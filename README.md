# RiFT is an AI product agent that helps non-technical people create right-first-attempt software prototypes. 

It guides users through five core questions and smart follow-ups, generating two artefacts: one used by the user to generate the rapid prototype, and one to communicate the idea to non-technical stakeholders with confidence.


# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1qcUqjGVgq7ycQtVQGyeRmKpfxvYir3tt

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
